## 保留的边界与风险

- 多集合保存/恢复仍是独立写入，不是一个全库事务；故障中断可能部分完成。本轮没有改表结构或大范围重写恢复机制。恢复前保留 JSON 与完整 D1 备份；自动恢复前快照写入失败时会中止恢复。
- 域名的 DNS 最终解析地址未由应用做 DNS 固定；逐跳检查覆盖显式 IP/URL，最终网络边界仍依赖 Workers 平台。不要把此修复描述为完整 DNS rebinding 防护。
- 请求驱动刷新在没有请求、没有外部调用现有认证 Cron 时不保证按时运行；KV 旧部署的计数/锁仍为 best effort，个人部署依赖 D1。
- 历史 alias 已多次修改而当前配置没有保留总数时，无法自动判断未知旧计数归属。现有 alias 行未删除，新计数使用固定 ID。
- JSON 是业务备份，不是全数据库与 Secrets 备份。大备份还受 D1 单值/运行时限制；保留完整 SQL/Time Travel 及独立 Secrets 恢复方案。未执行任何生产恢复/迁移。
- 尚未通过生产凭据验证登录后的 D1/KV 读写；公开网页或 GitHub 检查成功不等于生产数据持久化验证。
