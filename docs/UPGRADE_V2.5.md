# MiSub v2.5 历史兼容说明

本文仅记录早期代码变化。当前 zzpice 个人维护版已经基于 2.7.0 独立演进，部署与维护请使用
[主说明](../README.md) 和 [维护与恢复](PERSONAL-MAINTENANCE.md)。

早期版本移除了 VPS 探针，并引入操作符链；相关数据格式可参考 [迁移指南](MIGRATION_GUIDE.md)。
内置渲染器支持主要订阅客户端。现有个人部署关闭外部转换后端。

原先面向 Fork 的上游同步、合并和强制覆盖步骤已经移除，不适用于本仓库。
现有数据库不能按旧教程重置或重复初始化；需要迁移时先备份并在隔离环境验证。
保留原始 Git 历史以便追溯具体版本的变更。
